# Plant Disease Detection Using AI

🌿 **Live Website:** [Click here to open PlantCare](PASTE_YOUR_LIVE_WEBSITE_URL_HERE)

This project detects and classifies plant leaf diseases using image processing and a trained deep learning model.

## Features

* Upload a plant leaf image.
* View the predicted disease class.
* View the model's confidence score.
* Explore project results and evaluation.

**Note:** Predictions may be incorrect. Model performance is limited by the training dataset and evaluation results.
